# OIBsIP Internship Projects

Python Programming Internship at Oasis Infobyte

## Projects

### 1. BMI Calculator
GUI-based BMI calculator with:
- Input validation
- Color-coded results
- SQLite database for history
- Trend graph with matplotlib

### 2. Password Generator
Cryptographically secure password generator with:
- Password strength indicator
- Copy to clipboard
- Character type selection
- History (in-memory only)

### 3. Chat Application
Real-time multi-user chat with:
- Multiple rooms
- User authentication
- Message history
- 3-panel GUI

## Tech Stack
- Python 3.x
- tkinter
- sqlite3
- socket programming
